## ?? Decisões Chave de Performance

| Decisão | Razão | Trade-off |
|---------|-------|-----------|
| **Blittable JSON** | Zero-copy, acesso direto | Código customizado |
| **Memory-mapped I/O** | Zero-copy disk access | Platform-dependent |
| **MVCC** | Lock-free reads | Mais espaço em disco |
| **Multi-target Sparrow** | Compatibilidade ampla | Menos features modernas |
| **Server-only .NET 8** | Latest performance features | Só server usa |
| **Custom search engine** | Integração nativa | Mais manutenção |
| **Async everywhere** | Scalability | Complexidade |
| **Pooling universal** | Menos GC pressure | Mais código |
